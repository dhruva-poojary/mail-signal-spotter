# Mail Signal Spotter

Create a modern, responsive Email Spam Detector Web Application using HTML, CSS, JavaScript, and Python Flask.

Features:

1. Home Page

   - Professional header with project title "Email Spam Detector"

   - Brief explanation of how spam email detection works

   - Attractive and user-friendly UI

2. Spam Detection Section

   - Large text area where users can paste email content

   - "Check Email" button

   - Display result as:

     - Spam 🚫

     - Not Spam ✅

   - Show confidence percentage

3. Machine Learning Integration

   - Use a trained Naive Bayes model or suitable ML algorithm

   - Preprocess text using NLP techniques such as tokenization, stop-word removal, and stemming

   - Predict whether an email is spam or legitimate

4. Analytics Dashboard

   - Display total emails checked

   - Number of spam emails detected

   - Number of legitimate emails detected

   - Visual charts using Chart.js

5. Sample Emails

   - Provide example spam and non-spam emails for testing

   - One-click autofill option

6. Additional Features

   - Dark/Light mode toggle

   - Loading animation while prediction is processed

   - Mobile-friendly responsive design

   - Error handling for empty inputs

7. About Section

   - Explain the technologies used:

     - Python Flask

     - Machine Learning

     - NLP

     - HTML/CSS/JavaScript

   - Brief explanation of project objective

8. Design Requirements

   - Clean modern interface

   - Professional color scheme

   - Card-based layout

   - Smooth animations and hover effects

   - Suitable for final year college project demonstration

Ensure the website is fully functional, easy to understand, visually attractive, and optimized for a lecturer demonstration.
